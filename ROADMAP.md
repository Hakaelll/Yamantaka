# Roadmap

## 0.16.0: native Windows replacement

The owner confirmed final validation on 2026-11-04 and authorized completion of
the rewrite. The active application and build system are Rust-only. Flutter and
its mobile/web scaffolding remain recoverable from the archived Git checkpoint.

The release includes the immersive library, native PDF reader, study tools,
organization, migration and recovery workflows described in the
[README](README.md) and [product brief](PRODUCT.md).

## Maintenance

Address reported defects in reading, data compatibility, accessibility and
performance. Preserve existing libraries, immutable PDF inputs, local operation
and the approved visual identity. Keep comparisons and measurements tied to
actual artifacts; final owner acceptance does not create missing numeric traces.

Windows 10/11 x64 remains the supported platform. Printing, OCR, encrypted backups
and secondary reader windows are outside the completed feature scope. Historical
planning is available in the [Flutter checkpoint](docs/legacy/README.md).
