# Use the library in a smaller window

Yamantaka keeps 3D PDF covers at a readable size as the window changes. Cover size follows the available row width, rather than the space left below the toolbar. Use the catalogue scrollbar to reach book details or later rows in a short window.

In narrower windows, **Filters and sorting** opens the existing filter and ordering tools. An active filter highlights the control and exposes **Reset filters** beside it. The full filter row remains available in wide windows.

With enlarged text in a small window, the magnifying-glass button opens **Search library**. It uses the same title/author search as the larger search field. **Library view** gathers **Covers**, **List** and **Details** in a temporary menu. These controls remain available without permanently occupying several toolbar rows.

At very short heights, the library header and catalogue share one scrollbar. You can move the header out of the way and read a complete book row. At larger heights the catalogue retains its own scroll area.

Full-size books retain their spring tilt and elevation. Extra space above the cover keeps its projected volume clear of the toolbar while it rises. Miniatures retain tilt with a smaller elevation. **Reduced motion** keeps the 3D representation while disabling that decorative movement.
