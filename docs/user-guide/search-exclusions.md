# Manage search exclusions

Open **Tools → Global search**, choose **Manage index**, then **Excluded documents**. When local search is disabled, the search page provides an **Excluded documents** button directly.

Filter the list by title or author. **Previous** and **Next** move through pages of up to 80 books. **Refresh** reloads the saved decisions. Missing files remain listed so their exclusion can still be managed.

Choose **Include** beside a book to remove its search exclusion. The book becomes eligible for indexing. This action does not enable local search or start indexing. Return to the search page and start or resume indexing when you want its contents included.

**Back to search** preserves your search text and filters. These controls change the local search index state; they do not modify or remove PDF files.
