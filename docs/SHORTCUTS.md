# Atajos de Yamantaka 0.12

Los atajos se resuelven localmente y los personalizados se validan contra
conflictos. Los campos de texto conservan las teclas de edición y no disparan
navegación del lector.

| Atajo | Acción |
| --- | --- |
| `Ctrl+O` | Abrir PDF local |
| `Ctrl+K` | Paleta de comandos y diseños |
| `Ctrl+J` | Navegador documental unificado |
| `Ctrl+Mayús+J` | Panel lateral del lector |
| `Alt+←` / `Alt+→` | Atrás/adelante en el historial unificado |
| `Ctrl+Tab` / `Ctrl+Mayús+Tab` | Conmutador de documentos |
| `Page Up` / `Page Down` | Unidad anterior/siguiente |
| `Home` / `End` | Inicio/final del documento o lista activa |
| `F11` | Pantalla completa |
| `Escape` | Cerrar superficie temporal o salir de Foco/fullscreen |
| `Ctrl+↑` / `Ctrl+↓` | Reordenar la entrada enfocada de la cola |

La revisión de anotaciones, espacios, reglas y problemas expone las mismas
acciones mediante botones con tooltip y orden de foco. Drag and drop siempre
tiene alternativa por selector, acción masiva o teclado.
