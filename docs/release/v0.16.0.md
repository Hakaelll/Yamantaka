# Yamantaka 0.16.0

Native Windows PDF reading, study and personal-library management.

## Highlights

- A library of dimensional book covers with pointer physics, a compact continue-reading entry and refined light/dark desktop surfaces.
- A native reader with virtualized pages, retained previews, zoom refinement, layouts, reading environments, canonical navigation and optional comparison synchronization.
- Unicode passage and word selection, PDF search highlights, annotations, review, undo and Markdown/JSON export.
- Collections, tags, smart views, relations, revisions, local automation and opt-in full-text indexing.
- More resilient cover regeneration and metadata extraction under queue pressure, including transient unlock of protected PDFs.
- Reviewed migration, historical schema and backup compatibility, recovery, safe mode and independent portable storage.
- Session-only folder notifications with pause and revocation, without automatic document import or deletion.

## Native project cutover

The active application, Windows integration and build system now use Rust. Dart,
Flutter and the old mobile/web projects have been retired. The complete previous
source and tools are recoverable from
[`archive/flutter-before-rust-0.16.0`](https://github.com/Hakaelll/Yamantaka/tree/archive/flutter-before-rust-0.16.0).
Existing installed libraries and original PDFs were not removed or synchronized.
Migration compatibility and the historical SQL remain in the native application.

Windows icon resources now belong to `assets/branding/yamantaka.ico`; their
existing geometry and artwork are unchanged. This release includes all review 13
runtime behavior, with version and native build-resource changes for finalization.

## Install

Windows 10/11 x64. Extract the complete portable ZIP into a writable folder and
start `yamantaka/yamantaka.exe`. Keep PDFium, licenses and companion files beside
it. Flutter, Dart and Rust are not required. Portable data uses `rust-data` and
`rust-cache` in that folder; extracting a new package does not transfer an earlier
library. Use the reviewed backup or migration workflows.

The default compositor is wgpu/DirectX 12 with an alternate OpenGL startup path.
The distribution is unsigned. Compare its checksums with `SHA256SUMS.txt` from the
release before sharing it.

performance result or unreported procedure is invented.

Database schema v11, backups v1–v9, v9 export and continuity format v8 are retained.

requires consent and normal use remains local. Printing, OCR, encrypted backups
and secondary reader windows are outside the completed feature scope.
