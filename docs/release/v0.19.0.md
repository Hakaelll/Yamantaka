# Yamantaka 0.19.0

## Library and appearance

- Browse shelves with favorites, books in progress and collections in the sidebar.
- Switch between 3D covers, flat 2D covers and a list. Resize covers with the slider in the library header.
- Group books by author, collection, tag or reading status. The header keeps an active search visible in wide windows.
- The library, reader and Study tools use warm-white accents in dark mode and charcoal accents in light mode. Cover and annotation colors retain their original shades.

## Install or upgrade

Download the portable ZIP for Windows 10 or 11 x64. Extract the complete archive to a writable folder and open **yamantaka/yamantaka.exe**. Keep the companion files beside it. The archive is unsigned. Check its SHA-256 hash against **SHA256SUMS.txt**.

Export a backup before moving your portable library to a new folder. Restore it from Yamantaka's Storage settings.
