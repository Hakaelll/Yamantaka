# Yamantaka 0.18.0

## Reading and study

- Pinch on the trackpad or hold Ctrl and turn the mouse wheel to zoom. In comparison, zoom applies to the PDF under the pointer.
- Use the adjustable reading guide, the Study sidebar in wide windows and the compact toolbar next to selected passages.
- Draw ellipses and lines, and edit drawing position, size and stroke width. Preview PDF crops, copy them or save them as PNG.
- Filter notes by page, kind, color, tags and review state. Edit remains within reach in the comparison Notes tray.
- Build a summary for each book and export it as Markdown. Review cards store their next review date and can link back to the PDF.

## Install or upgrade

Download the portable ZIP for Windows 10 or 11 x64. Extract the complete archive to a writable folder and start **yamantaka/yamantaka.exe**. Keep the companion files beside it. The archive is unsigned. Verify the download against **SHA256SUMS.txt**.

Export a backup before moving your portable library to a new folder. Restore it from Yamantaka's Storage settings. Use 0.18.0 or later to access the new study tools and data in restored backups.
