# Yamantaka 0.19.1

## Reader and library

- Scanned PDFs bring the first page into focus sooner. Pinch and Ctrl + wheel zoom keep the point under the gesture or pointer in place in the reader and in comparison.
- The library loads PDF covers in batches for every visible book. Smaller textures keep memory bounded, and the library releases them as books leave the screen.
- Library and reader menus fit more window sizes and text scales.

In five runs per version with a 48-page scan, median time to the first sharp page fell from 892 ms to 750 ms. In a separate test with 400 PDFs, all 60 covers visible at 2560 × 1440 and all 80 visible at 3840 × 2160 loaded. The 80 visible covers used 25.9 MiB of GPU texture memory.

## Install or upgrade

Download the portable ZIP for Windows 10 or 11 x64. Extract the complete archive to a writable folder and open `yamantaka/yamantaka.exe`. Keep its companion files beside it. The archive is unsigned. Check its SHA-256 hash against `SHA256SUMS.txt`.

If you already use the portable version, export a backup from Storage before moving to a new folder. Open the new version and restore the backup from Storage.
