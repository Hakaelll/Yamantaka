Yamantaka 0.16.0 for Windows x64

Native Rust application for Windows 10/11 x64. Flutter, Dart and Rust are not
required to run this distribution. Extract the complete ZIP and start
 yamantaka/yamantaka.exe
Keep pdfium.dll, licenses and companion files beside the executable.

The default compositor uses DirectX 12 through wgpu. If startup cannot initialize
it, the application attempts the OpenGL compositor once in a fresh process.
Use --opengl to select the alternate compositor explicitly.

Portable bundles contain .yamantaka-rust-portable and use rust-data and
rust-cache beside the executable. Extract into a writable directory. Bundles
without that marker use the independent io.yamantaka.rust application identity.
Use the application's reviewed backup and import workflows to transfer a library;
do not manually copy a database while it is open. Existing installations and
original PDF files are not overwritten by extraction.

LICENSE contains the MIT terms for Yamantaka. Third-party code and fonts retain
their own licenses in THIRD-PARTY-NOTICES.txt and licenses/. SBOM.cdx.json records
components; Cargo.lock records the pinned dependency resolution.

The accompanying package-manifest.json lists bundled files and SHA-256 hashes.
SHA256SUMS.txt covers the archive and manifest. verification.json describes
packaging checks. Final validation was accepted by the owner on 2026-11-04;
packaging checks are not new runtime or numerical performance measurements.

This distribution is not Authenticode-signed. Verify its published checksums
against the release page before installing or sharing it.
