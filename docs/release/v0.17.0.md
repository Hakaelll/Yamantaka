# Yamantaka 0.17.0

## Read and study

- Select text to highlight, underline, copy or add a note from a compact toolbar next to the passage.
- Open **Study** to mark passages repeatedly or draw freehand, add arrows and frame parts of a page. Drawing works on scanned pages.
- Use the eraser to preview and remove a mark on the page. **Undo** restores it. Marks with written notes are protected.
- Open a note from its page indicator. Filter the Notes tray by page and review status.
- Shared controls, menus and focus states have a more consistent finish across the library, reader and settings. Study tools fit into a compact menu in smaller windows.

## Install or upgrade

Download `yamantaka-0.17.0-windows-x64-portable.zip` for Windows 10 or 11 x64. Extract the complete ZIP to a writable folder and run `yamantaka/yamantaka.exe`. Keep PDFium and the companion files with the executable. The archive is unsigned. Use `SHA256SUMS.txt` to verify your download.

Export a backup before moving an existing portable library to a new folder, then use Yamantaka's reviewed restore. Drawings are stored locally and included in v9 backups. Restoring a backup with drawings requires Yamantaka 0.17.0 or later. The app keeps original PDFs intact.

## Verification scope

Automated coverage includes erasing and restoring a drawing, protection for written notes, rotated geometry, the page filter and v9 backup restoration. Native captures cover light and dark themes and compact layouts at 200% text scale. The automated capture for note filters in comparison timed out.
